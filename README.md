# EVA-AI-01

MEGA / EVA-AI cryptocurrency analysis and paper-trading system.

## Project

This repository is the new GitHub home for the EVA-AI / MEGA project.

The system is designed around:

- Market Data
- Z-Score Signal
- HMM Market Regime
- GARCH Volatility
- Sentiment Analysis
- Correlation Filtering
- Risk Management
- Fitness Feedback Control (FFC)
- Paper Trading
- Performance Analysis
- Telegram Reporting

## Architecture

Binance Market Data
→ Data Validation
→ Feature Engineering
→ Signal Engine
→ Regime / Volatility
→ Risk Engine
→ Portfolio Engine
→ Paper Execution
→ Performance Tracking
→ Telegram

## Important

API keys, Telegram tokens, and other secrets must never be stored in this repository.

Secrets must be provided through environment variables or GitHub Actions / Railway secrets.
